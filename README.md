# 🛡️ Cryptizer Pro

**Cryptizer Pro** — это легкий и удобный инструмент для шифрования сообщений, созданный для безопасного общения в мессенджерах (Telegram, WhatsApp и др.). Он позволяет быстро зашифровать текст, отправить его другу и так же быстро расшифровать ответ через буфер обмена.

---

## ✨ Основные возможности

*   **Ультра-защищенное шифрование (AES-256-GCM)**: Использует 512-битный мастер-ключ и промышленный стандарт AES-256 в режиме GCM (Galois/Counter Mode). Это обеспечивает не только секретность, но и защиту от подмены текста.
*   **Интеграция с буфером обмена**: Шифруйте и копируйте одной кнопкой. Расшифровывайте текст прямо из того, что скопировали у друга.
*   **Удобное управление ключами**: Создавайте новые ключи или устанавливайте полученные от собеседника прямо в приложении.
*   **Безопасное хранение**: Ключи хранятся в локальном файле `secret.key`, который автоматически игнорируется Git (через `.gitignore`).
*   **Кроссплатформенность**: Работает на Windows, macOS и Linux.

---

## 🚀 Быстрый запуск

Мы подготовили автоматические скрипты для удобного старта:

### Для Windows:
Просто дважды кликните по файлу **`run.bat`**. Скрипт сам создаст виртуальное окружение и установит нужные библиотеки.

### Для Linux и macOS:
Запустите скрипт в терминале:
```bash
./run.sh
```

## 🛠 Инструкция по использованию

1.  **Начало (Обмен ключом)**:
    *   Если вы первый пользователь: Выберите **"Создать новый ключ"** в меню. Скопируйте его и передайте другу через защищенный канал.
    *   Если ключ прислал друг: Скопируйте его, выберите **"Ввести существующий ключ"** и вставьте.
2.  **Переписка**:
    *   Перейдите в **"Чат-режим"**.
    *   Нажмите **"1"**, введите сообщение. Оно автоматически зашифруется и попадет в ваш буфер обмена. Вставьте его в чат мессенджера (`Ctrl+V`).
    *   Когда друг пришлет ответ — скопируйте его зашифрованное сообщение в мессенджере и нажмите в скрипте **"2"**. Текст расшифруется мгновенно.
3.  **Безопасность**:
    *   Если нужно быстро удалить ключ — воспользуйтесь пунктом **"Удалить текущий ключ"** в главном меню.

## 📦 Установка вручную

Если вы не хотите использовать скрипты запуска:

1.  Установите Python (3.7+).
2.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите программу:
    ```bash
    python main.py
    ```

---

## ⚠️ Внимание!
**Никогда не передавайте файл `secret.key` или содержимое ключа через открытые каналы связи.** Используйте защищенные мессенджеры с E2E-шифрованием только для передачи ключа в первый раз.
